# Подтверждение дизайна

## Назначение

Использовать, чтобы не переносить дизайн в основной проект раньше времени.

## Правила

- Держать дизайн в черновике, пока нет явного одобрения.
- Не переносить вариант в основной проект до подтверждения.
- Отделять утвержденное от неподтвержденного.
- Если решение спорное, сначала показать его пользователю.

## Порядок работы

1. Проверить, готов ли вариант к показу.
2. Показать его пользователю.
3. Дождаться явного подтверждения.
4. Только потом переносить в основной проект.
