# История пользователя

Этот файл нужен для описания поведения и потребностей пользователя.

## Что нужно описать

- кто использует проект;
- какие задачи у пользователя есть;
- какие сценарии он проходит;
- какие случаи и отклонения нужно учитывать;
- что пользователь ожидает от проекта.

## Как заполнять

Пиши коротко, по делу и без технических деталей.
