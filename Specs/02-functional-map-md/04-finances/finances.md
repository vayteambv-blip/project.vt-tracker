# Финансы

Этот раздел описывает финансовую часть проекта.

## Что хранить

- подготовка и сдача объекта;
- материалы;
- оплата фирмам;
- аренда техники;
- непредвиденные расходы;
- базовая смета по проекту;
- дополнительные работы как отдельная доходная часть;
- дополнительные работы как отдельная строка внутри текущего проекта;
- итог по оплатам фирмам внутри проекта;
- остаток до оплаты.

## Что должно уметь

- показывать все расходы по проекту;
- показывать расходы по типам;
- считать итог по каждому проекту;
- считать итог по оплатам фирмам внутри проекта;
- считать прибыль как базовая смета плюс дополнительные работы минус расходы на подготовку и сдачу объекта, материалы, оплату фирмам, аренду техники и непредвиденные расходы;
- сводить все расходы в финальный итог без отдельной строки;
- показывать остаток до оплаты;
- показывать прибыль внутри финансов без отдельного экрана;
- показывать итог расходов и прибыль в одной карточке проекта;
- в списке проектов показывать только название и статус;
- оплата фирмам не хранится как отдельный финансовый блок фирмы, а идет через расходы проекта.
- дополнительные работы относятся к текущему проекту и не создают отдельный проект.

## Что важно

- каждый проект анализируется отдельно;
- прибыль считается по конечному результату, без лишней теории;
- хранить только текущие суммы, без истории старых сумм.
