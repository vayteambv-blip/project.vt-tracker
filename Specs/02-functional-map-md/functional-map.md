## Правило

- Каждый блок отвечает только за свою часть.
- Одинаковые данные не дублируются без необходимости.
- Если правило относится к конкретному блоку, оно хранится только в его разделе.
- Если правило касается нескольких блоков, в каждом из них остается только нужная часть без полного повтора.
