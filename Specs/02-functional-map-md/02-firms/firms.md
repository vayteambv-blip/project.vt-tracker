# Субподрядчики

Этот раздел описывает работу с субподрядчиками.

## Что хранить

- имя субподрядчика;
- налоговый номер;
- официальный зарегистрированный адрес;
- телефон;
- email;
- документы;
- текущий контракт по сотрудничеству;
- текущих рабочих, привязанных к субподрядчику;
- архив рабочих по каждому рабочему;
- документы рабочих, которые работают или работали через субподрядчика;
- отдельный список фактур как обзор по месяцам и годам;
- связанные проекты.

## Что должно уметь

- создавать субподрядчика;
- хранить субподрядчика на отдельной странице;
- прикреплять субподрядчика к проекту;
- видеть, какой субподрядчик работает на каком проекте;
- хранить документы субподрядчика отдельно;
- показывать только текущие документы субподрядчика по умолчанию;
- архив старых версий документов субподрядчика должен быть доступен отдельно;
- хранить рабочих отдельно внутри субподрядчика;
- хранить архив рабочих по каждому рабочему;
- хранить документы рабочих по субподрядчику;
- показывать отдельный список фактур субподрядчика;
- менять рабочих внутри субподрядчика без потери структуры;
- проверять полноту данных субподрядчика перед сохранением.

## Что важно

- рабочие всегда принадлежат субподрядчику;
- у проекта может быть несколько субподрядчиков;
- субподрядчики могут участвовать в нескольких проектах;
- субподрядчик не является клиентом;
- субподрядчик хранится отдельно от частного клиента;
- субподрядчик может выставлять фактуры, а оплата всегда идет через расходы проекта;
- субподрядчик может видеть историю выставленных фактур как обзор по месяцам и годам;
- у субподрядчика нет отдельного финансового блока;
- архив рабочих внутри субподрядчика нужен и должен хранить отдельных рабочих в архивном виде;
- документы и текущие контракты субподрядчика сохраняются как прикрепленные файлы;
- старые файлы остаются прикрепленными, если добавляются новые;
- отдельной истории контрактов по субподрядчику нет;
- субподрядчик может выполнять любой тип работ на разных проектах, без привязки к одной постоянной специализации;
- все оплаты идут через расходы проекта;
- в карточке субподрядчика достаточно отдельного списка фактур и рабочих;
- общую сумму по всем проектам субподрядчика хранить не нужно;
- общих заметок по субподрядчику хранить не нужно, заметки сохраняются только внутри проекта;
- если данных не хватает, форма сразу показывает недочеты и позволяет сохранить черновик;
- направление работ задается через проект, а не через карточку субподрядчика.
