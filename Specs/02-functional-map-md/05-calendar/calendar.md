# Календарь

Этот раздел описывает планирование проектов во времени.

## Что хранить

- проекты по направлениям работ;
- подготовленные проекты;
- проекты в процессе;
- завершенные проекты до переноса в архив;
- дату старта;
- дату окончания, если она известна;
- фирму, которая будет исполнять работу;
- уведомление о старте за 10 рабочих дней.

## Что должно уметь

- показывать отдельный календарь для каждого направления работ;
- открывать календарь по месяцам;
- видеть в каждом календаре подготовленные проекты;
- видеть в каждом календаре проекты в процессе;
- видеть в каждом календаре завершенные проекты до архива;
- видеть, какой проект стартует в конкретный день;
- видеть, когда проект должен закончиться;
- видеть, какая фирма привязана к проекту;
- переносить старт проекта на другую дату;
- видеть общий обзор по направлению и дате старта.

## Что важно

- календарь показывает только проекты;
- отдельные записи работ в календаре не нужны;
- календарь нужен для обзора, а не для дублирования данных.
