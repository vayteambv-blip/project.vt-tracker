# Возврат из архива

## Назначение

Использовать, когда завершенный проект нужно вернуть в работу без создания нового дубля.

## Правила

- Возвращается тот же проект, а не новая запись.
- Старые данные, документы, финансы, связи и история остаются на месте.
- После возврата нужно заново задать дату старта.
- После возврата проект снова идет по обычному рабочему протоколу.
- Проект снова должен появиться в календаре после установки новой даты.

## Порядок работы

1. Подтвердить, что проект возвращается из архива.
2. Восстановить его как тот же самый проект.
3. Задать новую дату старта.
4. Вернуть обычный рабочий поток.
5. Проверить календарь и активный статус.

## Финальная проверка

- проект вернулся как продолжение самого себя;
- данные не потерялись;
- новая дата старта задана;
- календарь снова показывает проект;
- дубль проекта не создан.
