# Клиенты

Этот раздел описывает, что система должна уметь делать с клиентами.

## Что хранить

- имя;
- фамилия;
- телефон;
- email;
- связанные проекты;
- адрес проживания.

## Что должно уметь

- создавать клиента;
- хранить данные частного клиента отдельно;
- привязывать клиента к проектам;
- открывать карточку клиента;
- видеть все связанные проекты.

## Что важно

- клиент не должен смешиваться с фирмой-исполнителем;
- клиентом считается только частный заказчик;
- у клиента нет налогового номера;
- документы клиента для создания не нужны;
- адрес проживания обязателен.
