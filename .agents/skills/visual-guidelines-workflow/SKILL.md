# Visual Guidelines Workflow

## Overview

Use this skill to keep the interface visually consistent and easy to read.

## Rules

- Keep one clear style across all screens.
- Use colors consistently for normal, success, warning, and error states.
- Keep typography readable and simple.
- Keep spacing, buttons, cards, lists, and tables visually aligned.
- Make empty, loading, error, current, and old states easy to understand.
- Keep mobile and desktop behavior consistent.

## Guidelines

### Colors

- Use one main color family for the interface.
- Use red only for errors and missing data.
- Use neutral tones for inactive or empty states.

### Typography

- Make headings easy to scan.
- Keep body text readable.
- Avoid mixing too many font styles.

### Components

- Keep buttons, inputs, cards, lists, and tables visually consistent.
- Keep status labels short and easy to recognize.

### States

- Show empty states clearly.
- Show errors clearly.
- Show current and old versions clearly.
- Keep loading states simple and calm.
