# Archive Return Workflow

## Overview

Use this skill when a project comes back from archive and must continue as the same project, not as a new one.

## Rules

- Return the archived project as the same project, not as a new project.
- Keep the existing data, history, documents, factures, and links.
- Set a new start date when the project returns.
- Apply the normal active-project protocol again after return.
- Put the project back into the calendar after the new start date is set.
- Keep the project editable like a normal active project.
- Keep reminders active again after the project returns.

## Workflow

1. Confirm that the project is being restored from archive.
2. Restore the full project state as it was before archiving.
3. Ask for or set a new start date.
4. Reapply the normal project flow.
5. Put the project back into the active calendar view.
6. Keep all existing history and linked data in place.

## Final Check

Before finishing, confirm:

- the project returned as a continuation of the same project;
- the data stayed intact;
- the new start date is set;
- the active project flow is restored;
- the project is visible again in the calendar;
- no new duplicate project was created.
