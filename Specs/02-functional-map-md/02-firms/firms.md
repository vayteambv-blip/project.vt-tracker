# Фирмы

Этот раздел описывает работу с фирмами, подрядчиками и субподрядчиками.

## Что хранить

- имя фирмы;
- налоговый номер;
- официальный зарегистрированный адрес фирмы;
- официальный телефон;
- мобильный телефон;
- email;
- документы;
- текущий глобальный контракт по сотрудничеству;
- текущих рабочих, привязанных к фирме;
- историю всех рабочих, которые работали через фирму;
- документы рабочих, которые работали через фирму, по тем же правилам текущей и архивной версии;
- отдельный список всех проектов, в которых участвовала фирма, как обзор с видом работ.

Фирма-исполнитель - это субподрядчик, который выполняет работу для моей фирмы.

## Что должно уметь

- создавать фирму;
- хранить фирму на отдельной странице;
- прикреплять фирму к проекту;
- видеть, какая фирма работает на каком проекте;
- хранить документы фирмы отдельно;
- показывать только текущие документы фирмы по умолчанию;
- архив старых версий документов фирмы должен быть доступен отдельно;
- хранить рабочих отдельно внутри фирмы;
- хранить историю всех рабочих по фирме;
- хранить документы рабочих по фирме;
- показывать отдельный список всех проектов фирмы как быстрый обзор с видом работ.
- менять рабочих внутри фирмы без потери структуры.
- не хранить постоянную специализацию фирмы по направлению работ;
- задавать направление работ через проект, а не через карточку фирмы.

## Что важно

- рабочие всегда принадлежат фирме;
- у проекта может быть несколько фирм;
- одна фирма может участвовать в нескольких проектах.
- фирма-исполнитель не является клиентом;
- фирма-исполнитель хранится отдельно от частного клиента;
- фирма-исполнитель может выставлять фактуры и получать оплату.
- фирма-исполнитель может видеть историю выставленных фактур как обзор по связанным проектам.
- история рабочих внутри фирмы нужна и должна хранить всех рабочих, которые когда-либо работали через эту фирму.
- документы и текущие контракты фирмы сохраняются как прикрепленные файлы; старые файлы остаются прикрепленными, если добавляются новые.
- отдельной истории контрактов по фирме нет.
- фирма может выступать как фирма-исполнитель, так и как фирма-заказчик в разных проектах.
- фирма может выполнять любой тип работ на разных проектах, без привязки к одной постоянной специализации.
- в карточке фирмы достаточно отдельного списка проектов как обзора с видом работ.
- общую сумму по всем проектам фирмы хранить не нужно.
- общих заметок по фирме хранить не нужно, заметки сохраняются только внутри проекта.

## Рабочие фирмы

По каждому рабочему отдельно хранить:

- имя;
- фамилию;
- телефон;
- папку документов;
- отдельную папку для дополнительных вложений внутри документов.
