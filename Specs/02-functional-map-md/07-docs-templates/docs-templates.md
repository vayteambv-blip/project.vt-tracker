# Документы и шаблоны

Этот раздел описывает хранение файлов, шаблонов и документов.

## Что хранить

- документы внутри общего раздела `Документы`:
  - смету проекта;
  - текущий контракт по проекту;
  - текущий контракт по фирме;
  - фактуры;
  - акты сдачи, если они есть;
- другие нужные файлы и документы без ограничений по типу;
- шаблоны проектов;
- шаблоны фирм;
- PDF-файлы с документами или скриншоты фотографий как обычные файлы.

## Что должно уметь

- хранить документы по проекту;
- хранить документы отдельно по фирме;
- хранить документы в общем типе хранения `Документы`;
- визуально разделять файлы по типам;
- хранить смету и контракт как отдельные типы файлов;
- хранить фактуры как отдельный тип файлов;
- хранить дополнительные работы как отдельный тип файлов;
- хранить смету проекта внутри `Документы`;
- хранить текущий контракт по проекту и текущий контракт по фирме внутри `Документы`;
- хранить документы проекта только внутри карточки проекта;
- хранить документы фирмы только внутри карточки фирмы;
- использовать шаблоны как заготовки;
- прикреплять PDF-файлы к нужным сущностям;
- прикреплять, скачивать и отправлять документы внутри системы;
- отправлять документ на email прямо из документов;
- отправлять документы на email прямо из карточки файла для проекта и фирмы;
- не смешивать файлы проекта и фирмы;
- показывать документы проекта внутри карточки проекта;
- показывать документы фирмы внутри карточки фирмы;
- в каждой карточке показывать только свои документы;
- применять один и тот же принцип фильтров по типам для проекта и фирмы;
- фильтровать документы по типу;
- фильтровать смету и контракт как отдельные типы;
- фильтровать фактуры как отдельный тип;
- фильтровать дополнительные работы как отдельный тип;

## Что важно

- автозаполнение не нужно;
- шаблон - это только заготовка с нужными полями;
- PDF нужен как обычный формат хранения документов, как и скриншот фотографии, а не как отдельная функция экспорта;
- при создании проекта обязательна только согласованная смета, остальные документы можно добавлять позже;
- смета хранится как файл внутри `Документы`, без отдельного списка смет;
- если добавляется новый файл документа, старый файл уходит из основного списка и остается как архивная версия;
- если есть одинаковые прототипы документов, один из них должен быть текущим;
- пометка `старый` не нужна;
- акты сдачи хранятся как обычный файл без отдельного фильтра;
- у сметы, контракта и фактуры должен быть виден текущий файл, если есть несколько версий;
- в карточке файла должно быть видно, к какому проекту или фирме он относится;
- файл нельзя удалять полностью, только заменять новым;
- старые версии хранятся как архив и открываются по запросу;
- старые версии можно открывать и скачивать сразу из карточки файла;
- старую версию можно восстановить как текущую в два клика;
- в карточке файла видно, что есть архивная версия;
- архивную версию можно переименовать вручную;
- для каждого файла хранится только одна архивная версия;
- текущую версию тоже можно переименовать вручную;
- в карточке файла есть только одна текущая версия и одна архивная версия;
- и текущая, и архивная версии указываются прямо в названии;
- при восстановлении старая версия автоматически становится текущей и получает новый порядковый номер;
- внутри документов не нужен отдельный поиск по проекту, фирме или дате загрузки;
- в общем списке документов по умолчанию показываются только текущие файлы;
- никакие отдельные подпапки внутри `Документы` не нужны;
- внутри `Документы` файлы должны быть разделены по типам и доступны для фильтра;
- отдельного списка контрактов по проекту не нужно.
