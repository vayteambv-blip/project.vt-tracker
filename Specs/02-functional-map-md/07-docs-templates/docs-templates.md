# Документы

Этот раздел описывает текущее хранение записей документов в системе.

## Что хранить

- документы проекта;
- документы субподрядчика;
- связанные документы;
- название документа;
- контекст документа;
- номер версии;
- заметку к документу.

## Что должно уметь

- хранить документы проекта отдельно по контексту от документов субподрядчика;
- хранить связанные документы отдельно как отдельный контекст;
- показывать документы в общем разделе `Документы`;
- редактировать, сохранять и удалять запись документа;
- показывать для каждой записи название, контекст, версию и заметку;
- использовать шаблоны как будущую отдельную возможность, а не как текущую базу;
- хранить только текущую запись без отдельного архива версий в текущем слое.

## Что важно

- автозаполнение не нужно;
- шаблон и история версий относятся к будущему этапу;
- в карточке файла видно его текущий контекст;
- внутри `Документы` записи доступны как отдельные строки без подпапок;
- в общем списке документов показываются только текущие записи;
- отдельного поиска по проекту, субподрядчику или дате загрузки внутри документов сейчас не нужно;
- документы клиента в систему не входят.
