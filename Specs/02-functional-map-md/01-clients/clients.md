# Клиенты

Этот раздел описывает работу с клиентами проектов.

## Что хранить

- тип клиента:
  - частный клиент;
  - фирма-заказчик;
- для частного клиента:
  - имя;
  - фамилия;
  - адрес проживания;
  - телефон;
  - email;
- для фирмы-заказчика:
  - название фирмы;
  - контактное лицо;
  - адрес;
  - телефон;
  - email;
- связанные проекты.

## Что должно уметь

- создавать клиента;
- открывать карточку клиента;
- привязывать клиента к проектам;
- видеть все связанные проекты;
- проверять полноту данных клиента перед сохранением.

## Что важно

- клиент не должен смешиваться с субподрядчиком;
- клиентом может быть только частный заказчик или фирма-заказчик;
- фирма-заказчик не является субподрядчиком;
- документы клиента для создания не нужны;
- если данных не хватает, форма сразу показывает недочеты и позволяет сохранить черновик;
- для частного клиента обязательны имя, фамилия, адрес проживания, телефон и email;
- для фирмы-заказчика обязательны название фирмы, контактное лицо, адрес, телефон и email;
- тип клиента должен быть указан сразу;
- адрес указывается по типу клиента: адрес проживания у частного клиента, адрес фирмы у фирмы-заказчика.
