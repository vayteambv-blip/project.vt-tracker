# Клиенты

Этот раздел описывает, что система должна уметь делать с клиентами.

## Что хранить

- имя;
- налоговый номер;
- телефон;
- email;
- документы;
- связанные проекты;
- тип клиента: фирма-заказчик или частный клиент;
- отдельный адрес в зависимости от типа клиента.

## Что должно уметь

- создавать клиента;
- разделять клиентов по типам;
- хранить общие данные клиента отдельно;
- хранить отдельный адрес в зависимости от типа клиента;
- привязывать клиента к проектам;
- открывать карточку клиента;
- видеть все связанные проекты.

## Что важно

- клиент не должен смешиваться с фирмой-исполнителем;
- для частного клиента отдельно хранится адрес проживания;
- для фирмы-заказчика отдельно хранится адрес фирмы.
