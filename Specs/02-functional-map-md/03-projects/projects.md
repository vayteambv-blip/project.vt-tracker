# Проекты

Этот раздел описывает главный объект системы.

## Что хранить

- дата старта, если она уже задана;
- дата окончания, если она уже известна;
- текущий статус;
- адрес проекта;
- клиент;
- направления работ;
- список фирм, участвующих в проекте, с указанием вида работ;
- документы;
- фото;
- отдельные фотографии вне отчетов;
- отдельный список отчетов проекта;
- итог по проекту;

## Что должно уметь

- создавать проект;
- создавать проект заранее как подготовленный;
- проект со статусом `будущий` остается вне календаря, пока у него нет даты старта;
- перед созданием проверять наличие:
  - названия проекта;
  - данных самого проекта;
  - данных клиента;
  - адреса;
  - email;
  - номера телефона;
  - сметы, заранее одобренной клиентом;
- при создании проекта обязательна только согласованная смета, остальные документы можно добавлять позже;
- текущий контракт для создания проекта не обязателен;
- связывать проект с клиентом;
- задавать одно или несколько направлений работ для проекта;
- переводить подготовленный проект в процесс, когда я решу его начать;
- задавать дату старта перед переводом в процесс;
- если дата старта задана в проекте, она автоматически попадает в календарь;
- если дата старта меняется в календаре, она автоматически обновляется в проекте;
- если выбрано направление работ, проект автоматически попадает в нужный календарь этого направления;
- если дата старта еще не задана, проект остается в списке будущих проектов вне календаря;
- добавлять фирмы в проект;
- показывать список фирм проекта и вид работ, который выполняла каждая фирма;
- добавлять документы и фото;
- добавлять отдельные фотографии вне отчетов;
- добавлять отчеты с фотографиями;
- закрывать проект вручную;
- переносить завершенный проект в архив вручную кнопкой;
- возвращать проект из архива обратно кнопкой, если нужно;
- показывать итог по проекту.

## Что важно

- проект и объект считаются одним и тем же;
- у проекта один клиент;
- у клиента может быть много проектов на разных локациях;
- достаточно только адреса проекта;
- список фирм проекта должен показывать, какие работы выполняла каждая фирма;
- в списке фирм проекта не хранить суммы и контракты;
- документы хранятся внутри проекта без отдельного списка;
- фотографии могут храниться отдельно вне отчетов;
- отчеты хранятся внутри проекта отдельным списком;
- каждый отчет может содержать фотографии;
- расходы ведутся только в финансах и в проекте не дублируются;
- фактуры хранятся в финансах и документах, без отдельного списка;
- отдельные записи работ не хранятся как сущности;
- рабочих отдельно в проекте не хранить;
- общие заметки по проекту не хранить, заметки идут внутри отчетов;
- проект должен быть основой для всех остальных данных.
- после создания проект можно редактировать.
