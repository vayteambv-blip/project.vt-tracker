# Визуальные правила

## Назначение

Использовать, когда нужно привести интерфейс к одному понятному стилю без изменения бизнес-логики.

## Правила

- Держать единый стиль на всех экранах.
- Использовать понятные цвета для обычного, успешного, предупреждающего и ошибочного состояния.
- Делать типографику читаемой.
- Сохранять единый ритм карточек, списков, таблиц и кнопок.
- Ясно показывать пустые, загружаемые, старые и ошибочные состояния.
- Проверять, что интерфейс одинаково работает на телефоне и на компьютере.

## Краткие ориентиры

- Красный использовать только для ошибок и недостающих данных.
- Текст должен читаться сразу.
- Состояния должны быть понятны без пояснений.
- Интерфейс не должен распадаться на разные стили.
