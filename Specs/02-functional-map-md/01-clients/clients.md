# Клиенты

Этот раздел описывает работу с клиентами проектов.

## Что хранить

- тип клиента:
  - частный клиент;
  - клиент-фирма;
- для частного клиента:
  - имя;
  - фамилия;
  - адрес проживания;
  - телефон;
  - email;
- для клиент-фирмы:
  - название;
  - адрес;
  - телефон;
  - email;
  - налоговый номер;
- связанные проекты.

## Что должно уметь

- создавать клиента;
- открывать карточку клиента;
- привязывать клиента к проектам;
- видеть все связанные проекты;
- проверять полноту данных клиента перед сохранением.

## Что важно

- клиент не должен смешиваться с субподрядчиком;
- клиентом может быть только частный клиент или клиент-фирма;
- клиент-фирма не является субподрядчиком;
- документы клиента для создания не нужны;
- если данных не хватает, форма сразу показывает недочеты и позволяет сохранить черновик;
- для частного клиента обязательны имя, фамилия, адрес проживания, телефон и email;
- для клиент-фирмы обязательны название, адрес, телефон, email и налоговый номер;
- тип клиента должен быть указан сразу;
- адрес указывается по типу клиента: адрес проживания у частного клиента, адрес компании у клиент-фирмы.
