# Финансы

Этот раздел описывает финансовую часть проекта.

## Что хранить

- подготовка и сдача объекта;
- материалы;
- оплата субподрядчикам;
- аренда техники;
- непредвиденные расходы;
- базовая смета по проекту;
- итог по оплатам субподрядчикам внутри проекта;
- остаток до оплаты;
- прибыль;
- расходы по типам.

## Что должно уметь

- показывать все расходы по проекту;
- показывать расходы по типам;
- считать итог по каждому проекту;
- считать итог по оплатам субподрядчикам внутри проекта;
- считать прибыль как базовая смета минус расходы на подготовку и сдачу объекта, материалы, оплату субподрядчикам, аренду техники и непредвиденные расходы;
- сводить все расходы в финальный итог без отдельной строки;
- показывать остаток до оплаты;
- показывать прибыль внутри финансов без отдельного экрана;
- показывать итог расходов и прибыль в одной карточке проекта;
- показывать внутри проекта отдельный вход в финансы с перечнем расходов;
- оплата субподрядчикам идет через расходы проекта;
- дополнительные работы относятся к отдельному проекту со своей согласованной сметой и не создают строку в финансах текущего проекта;
- показывать сумму по оплатам субподрядчикам внутри проекта.

## Что важно

- каждый проект анализируется отдельно;
- прибыль считается по конечному результату, без лишней теории;
- хранить только текущие суммы, без истории старых сумм;
- итог по проекту не дублируется в карточке проекта;
- финансы являются единственным местом для денежного итога проекта.
