# Документы и шаблоны

Этот раздел описывает хранение файлов, версий и шаблонов.

## Что хранить

- документы проекта;
- документы субподрядчика;
- документы рабочих субподрядчика;
- смету проекта;
- контракт проекта;
- контракт субподрядчика;
- фактуру;
- акты сдачи, если они есть;
- другие нужные файлы и документы без ограничения по типу;
- шаблоны проектов;
- шаблоны субподрядчиков.

## Что должно уметь

- хранить документы проекта отдельно от документов субподрядчика;
- хранить документы субподрядчика отдельно от проекта;
- хранить документы рабочих отдельно внутри субподрядчика;
- показывать документы проекта только в карточке проекта;
- показывать документы субподрядчика только в карточке субподрядчика;
- хранить фактуру в связи с проектом и показывать ее в проекте и в карточке субподрядчика;
- хранить документы в общем типе хранения `Документы`;
- визуально разделять файлы по типам;
- хранить смету и контракт как отдельные типы файлов;
- хранить фактуру отдельно от обычных файлов;
- прикреплять, скачивать и отправлять документы внутри системы;
- отправлять документ на email прямо из карточки файла;
- использовать шаблоны как заготовки;
- фильтровать документы по типу;
- открывать старые версии файлов из карточки документа;
- восстанавливать текущую версию как основную.

## Что важно

- автозаполнение не нужно;
- шаблон - это только заготовка с нужными полями;
- фактура - это счет;
- фактуру может выставлять частный клиент, фирма-заказчик или субподрядчик;
- смета хранится как отдельный файл;
- контракт хранится как отдельный файл;
- фактура хранится с историей изменений;
- у рабочих субподрядчика должны быть текущие и архивные версии документов;
- если добавляется новый файл документа, старый файл остается в истории;
- старые версии можно открывать и скачивать;
- текущую версию можно восстановить как основную;
- в карточке файла видно, к какому проекту или субподрядчику он относится;
- внутри `Документы` файлы должны быть разделены по типам и доступны для фильтра;
- в общем списке документов по умолчанию показываются только текущие файлы;
- отдельного списка контрактов по проекту не нужно;
- отдельного поиска по проекту, субподрядчику или дате загрузки внутри документов не нужно;
- документы клиента в систему не входят.
