# Шаблон отложенного плана

Этот файл нужен для задач, которые пока неактивны.

## Что сюда писать

- название отложенной задачи;
- почему задача отложена;
- что нужно для ее запуска;
- когда можно вернуться к задаче.

## Правило

Сюда не складывают активные задачи и не дублируют записи из `active`.
