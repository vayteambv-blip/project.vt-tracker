# Рабочий процесс спека

Этот skill нужен, чтобы держать проектные материалы в порядке.

## Назначение

Помогает вести проект так, чтобы:

- сначала был бизнес-контекст;
- потом функционал;
- потом будущие идеи;
- отдельно были технические материалы;
- отдельно были истории пользователей;
- отдельно были планы разработки.

## Правила

- Не создавать дубли одного и того же материала.
- Не смешивать спеки и планы разработки.
- Всегда писать материалы на русском языке.
- Новые документы класть только в нужную папку.

## Что использовать

- `спецификации/бизнес-контекст.md`
- `спецификации/функции/функции.md`
- `спецификации/будущие-идеи.md`
- `спецификации/технические/технические.md`
- `спецификации/история-пользователя/история-пользователя.md`
- `дорожная-карта/дорожная-карта.md`
- `планы-разработки/active/планы-работ.md`
