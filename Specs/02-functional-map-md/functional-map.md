# Functional Map

Этот спек разбивает проект на главные функциональные блоки. Здесь собраны только самые важные функции, без лишних повторов.

## Самые важные функции

- Клиенты
- Фирмы
- Проекты
- Финансы
- Календарь
- Отчеты
- Документы и шаблоны
- Архив

## Структура

- `01-clients/clients.md`
- `02-firms/firms.md`
- `03-projects/projects.md`
- `04-finances/finances.md`
- `05-calendar/calendar.md`
- `06-reports/reports.md`
- `07-docs-templates/docs-templates.md`
- `08-archive/archive.md`

## Правило

- Каждый блок описывает только свою функцию.
- Одинаковые данные не дублируются в разных блоках без необходимости.
- Функции описываются по порядку, чтобы потом их было легко переносить в следующие спеки.
