# Архив

Этот раздел описывает завершенные проекты.

## Что хранить

- только завершенные проекты;
- год;
- месяц;
- раздел работ;
- клиента;
- все данные проекта внутри архива.

## Что должно уметь

- переносить проект в архив вручную;
- возвращать проект из архива обратно вручную кнопкой;
- открывать архив как отдельный блок;
- искать проект по году;
- искать проект по месяцу;
- искать проект по разделу;
- искать проект по клиенту;
- быстро открывать нужный архивный проект.

## Что важно

- архив содержит только завершенные проекты;
- архив по умолчанию открывается на текущем году;
- разделы архива = кровля, фасады, внутриотделочные работы, глобальная стройка;
- возврат из архива происходит только вручную.
